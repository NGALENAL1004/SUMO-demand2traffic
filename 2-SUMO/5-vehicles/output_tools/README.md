# Vehicle-class assignment diagnostics

`person_to_emissionClass.csv` is generated by `../vehicles.ipynb`. It contains:

| Column | Meaning |
|---|---|
| `person_id` | SUMO/Eqasim person identifier |
| `emissionClass` | Assigned HBEFA4 emission class |
| `vTypeId` | SUMO vehicle-type identifier referenced by car trips |

Use this table to reproduce class counts, join simulated emissions back to
persons, and audit the deterministic assignment.

The reference output contains 10,569 car users. The number of rows must equal
the number of distinct persons with at least one car `personTrip` in
`population_all_with_vtypes.rou.xml`.

The CSV is generated and not tracked by Git. Only this README and `.gitignore`
are retained.

# Diagnostics d’attribution des classes de véhicules

`person_to_emissionClass.csv` est produit par `../vehicles.ipynb`. Il contient :

| Colonne | Signification |
|---|---|
| `person_id` | Identifiant de personne SUMO/Eqasim |
| `emissionClass` | Classe d’émissions HBEFA4 attribuée |
| `vTypeId` | Identifiant du type de véhicule SUMO référencé par les trajets en voiture |

Cette table permet de reproduire les effectifs par classe, de rattacher les
émissions simulées aux personnes et d’auditer l’attribution déterministe.

La sortie de référence contient 10 569 automobilistes. Le nombre de lignes
doit être égal au nombre de personnes distinctes ayant au moins un
`personTrip` en voiture dans `population_all_with_vtypes.rou.xml`.

Le CSV est généré et n’est pas suivi par Git. Seuls ce README et `.gitignore`
sont conservés.
