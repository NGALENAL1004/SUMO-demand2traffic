# Trip-conversion diagnostic outputs

This local folder contains the tabular diagnostics generated by
`../trips.ipynb`.

| File | Interpretation |
|---|---|
| `eqasim_pt_sumo_line_mapping.csv` | Operational Eqasim-leg to SUMO-line mapping |
| `eqasim_pt_sumo_line_mapping_debug.csv` | Full matching method, status, score, and metadata |
| `eqasim_pt_sumo_line_mapping_unmatched.csv` | Rows without a usable SUMO PT line |
| `population_all.log.csv` | Conversion status and reason for every Eqasim person |

The first three files use a semicolon separator. `population_all.log.csv`
uses a comma separator.

Before accepting the converted population:

1. count matched and unmatched PT rows;
2. inspect every `match_status` other than `ok`;
3. group `population_all.log.csv` by `status`;
4. examine representative reasons for `skipped_no_route`, `skipped_pt`, and
   `skipped_other`;
5. report the number of excluded persons with the simulation results.

These files are generated and not tracked by Git. Only this README and
`.gitignore` are retained.

# Diagnostics de conversion des déplacements

Ce dossier local contient les diagnostics tabulaires produits par
`../trips.ipynb`.

| Fichier | Interprétation |
|---|---|
| `eqasim_pt_sumo_line_mapping.csv` | Appariement opérationnel entre étapes Eqasim et lignes SUMO |
| `eqasim_pt_sumo_line_mapping_debug.csv` | Méthode, statut, score et métadonnées détaillés |
| `eqasim_pt_sumo_line_mapping_unmatched.csv` | Lignes sans offre TC SUMO utilisable |
| `population_all.log.csv` | Statut et motif de conversion de chaque personne Eqasim |

Les trois premières tables utilisent le point-virgule comme séparateur.
`population_all.log.csv` utilise la virgule.

Avant de valider la population convertie :

1. compter les lignes TC appariées et non appariées ;
2. examiner chaque `match_status` différent de `ok` ;
3. regrouper `population_all.log.csv` par `status` ;
4. étudier des motifs représentatifs de `skipped_no_route`, `skipped_pt` et
   `skipped_other` ;
5. mentionner le nombre de personnes exclues avec les résultats de simulation.

Ces fichiers sont générés et ne sont pas suivis par Git. Seuls ce README et
`.gitignore` sont conservés.
